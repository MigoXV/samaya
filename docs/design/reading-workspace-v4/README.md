# 阅读工作区 v4：设计契约

本次使用 MANAS Migrate 模式，苍渊·白垣双主题共用布局。只调整空间分配、内容层级与阅读交互，不增加后端状态体系。

## 浏览器基线

1440×900 应用视口，真实会话，只读检查：

| 区域 | v3 实测 |
| --- | ---: |
| 总览工具栏 | 64px |
| 搜索筛选 | 56px |
| 最近范围横栏 | 44px |
| 工作区正文起点 | 357px |
| 阅读窗口 | 346.125px |
| 固定输入区 | 196.875px |

旧专注状态仅将详情从 560px 加宽到 1080px，阅读窗口高度没有改善。

## 布局契约

- 总览为导航、两层紧凑工具区、任务列表；最近 10/20 数量和更新动作进入筛选行。
- 进入任务替换为 304px 任务侧栏与完整任务工作区，移除常驻项目导航和宽表。
- 专注隐藏任务侧栏，同一个工作区保持挂载；总览管理控件退出。
- 桌面页头 48+40=88px，默认编辑器约 104px；900px 视口阅读容器至少 680px。
- 1100px 以下使用任务抽屉。手机首页仍为总览，进入任务后保留返回、身份与全局决策入口。
- 普通正文默认最大宽 960px；宽阅读和代码、差异可使用更宽空间。

## 组件与状态

| 组件 | 正常 | 异常／异步 | 操作与恢复 |
| --- | --- | --- | --- |
| 任务侧栏 | 稳定最近集合，标题／状态／短进展 | 范围外运行、请求、未知 | 打开任务，查看全局队列，手动更新集合 |
| 工作区页头 | 身份、项目简称、执行状态 | 断连、过期、停止处理中 | 返回、专注、状态详情、目录上下文 |
| 对话 | 原生消息顺序、连续文本 | 历史失败、流式片段缺口 | 重载、加载更早、返回最新、定位要求 |
| 工具记录 | 简短事实，默认折叠 | 执行中／非零退出码保留摘要 | 展开命令、输出、退出码；不推断目标失败 |
| 编辑器 | 短输入紧凑，多行自适应 | 提交中、结果未知、不可发送原因 | 发送／追加、停止确认、展开编辑、帮助 |
| 决策入口 | 任务数与请求数区分 | 待确认／失效／异地处理 | 复用已有请求组件，不抢焦点 |

目录完整路径、核对时间、技术上下文按需查看。移除重复最近要求；零子任务和零后台命令不独占一行。正文 16px，紧凑控件 32px，触屏关键操作 44px，复用当前等线风格字体和锁定语义色。

## 监控边界

现有 useMonitor 获取全部记录，useRecentTasks 仅截取显示集合。后台监控目录、已加载会话和事件核对不接收最近数量。保留此机制，给范围外运行与待处理提供全局入口，不让显示上限变成监控上限。
