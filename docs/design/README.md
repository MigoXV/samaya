## 状态矩阵

| 场景 | 页面行为 | 恢复路径 |
| --- | --- | --- |
| 首次加载 | 会话列表／历史加载提示，发送禁用 | 服务就绪后读快照 |
| 无会话 | 目录选择和新建入口 | 创建后进入当前对话 |
| 无搜索结果 | 保留筛选并显示无结果 | 清除筛选，或加载更多 |
| 运行中 | 显示轮次状态，输入可准备草稿，发送禁用 | 等待完成或停止本轮 |
| 等待审批／输入 | 对话中显示真实请求表单 | 提交一次，其他页面随后看到请求消失 |
| 轮次失败／中断 | 保留历史、错误或停止说明 | 用户继续发送新任务 |
| 网页／服务断连 | 分别显示连接状态；不把任务标成停止 | 自动重连、重新读取；不重发任务 |
| 提交结果未知 | 保留操作编号，阻止继续提交 | 查询回执；用户核查实际产物后明确解除限制 |
| 清理部分成功 | 逐项结果、保留失败选择 | 检查失败原因后重试所选项 |
| 工作区切换 | 运行时阻止切换，空闲时核对服务端 cwd | 下一轮验证项目指令；原后台命令保留目录 |
| 归档历史 | 只读显示，恢复归档后可继续 | 会话管理的恢复归档操作 |

主对话采用实时工作台＋内容详情；清理页采用列表与搜索；设置采用设置与表单。工具输出和代码差异按需展开，消息不套卡片。窄屏保留对话与输入，导航和详情进入独立浮层；弹窗使用原生 dialog 管理焦点、Escape 和焦点返回。

初次浏览器检查发现窄屏“详情”换行、长命令占据正文和阅读停在旧消息的问题，已分别修正为不换行控制、折叠单行摘要和靠近底部时跟随输出。实际色值对比度与浏览器检查结果见 ../verification.md。

## MCP 增量设计

[Figma MCP 交互画板](https://www.figma.com/design/qaGSrQhakH253tizxKkoae?node-id=4-43)：标准表单 `4:97`，URL／窄屏 `4:122`，工具结果 `4:136`，状态恢复规范 `4:141`，真实工具审批补充 `5:55`。使用原有 Input / Button 实例、语义变量和 Noto Sans SC 文字样式；没有新增色板或截图铺底。先完成设计与截图核对，再实现 `mcp.tsx`、`mcp-schema.ts` 及局部样式。字段顺序来自服务端，内容宽度适应对话栏；40px 控件、24px 桌面／16px 窄屏内距沿用设计。

状态覆盖：输入／字段错误／提交中／已处理／等待外部流程／断连／提交结果不确定／不支持模式。错误使用文字和焦点，禁用状态同时说明原因；不把 URL 打开视为成功，也不把轮次结束视为请求已取消。输入草稿不跨刷新保存。

| 状态 | 行为 |
| --- | --- |
| 初次使用／无效存储值 | 白垣 |
| 已保存白垣或苍渊 | 首屏提前应用，不随系统变化 |
| 跟随系统 | 按系统解析，系统变化时同步 |
| 其他同源标签页修改 | 同步选择和实际外观 |
| 浏览器禁止保存 | 本页仍可切换，显示说明 |
| 对话运行、MCP 等待输入、弹窗已打开 | 只更新外观，保留业务状态及焦点 |

浏览器验证覆盖双主题 1440×960 和 390×844、原生选择框、按钮 hover/focus/disabled、选中会话、MCP 字段错误、长路径、长日志及弹窗焦点返回。截图位于 `.samaya/screenshots/theme-*.png`，测试数据和真实 Codex 历史的边界见验收记录。
