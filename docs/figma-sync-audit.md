# Figma 同步复核 · 2026-10-13

复核范围：对话工作区、共享侧栏、新会话、计划模式、模型选择，以及设置与任务通知。设计来自 [Samaya Figma 文件](https://www.figma.com/design/TZOGfIsv1ESAQckxwg4lpa)，包括白垣、苍渊和响应式状态。

## 修正遗漏

- 工具摘要显示实际批次数量及原生状态，全部成功完成时使用“完成 N 次工具调用”。补齐设计中的 12px 完成图标和展开箭头，两主题分别使用原始资源；保留键盘展开、原始记录和底部收起入口。
- 共享侧栏补齐品牌右侧收起入口，收起后仍可从主区域展开；收起操作将键盘焦点移至展开入口。恢复设计中的顶部间距、品牌高度及导航间距，待处理数量右对齐。
- 新会话复用既有任务的顶部工具栏、标题和内容页签。切换页签或侧栏不会丢失草稿；发送前的产物页明确显示空状态。创建新会话时恢复对话页签。

## 尚存功能差异

设计中的新会话输入器包含发送前模型选择。当前模型选择接口要求已有会话，新会话发送前仍无法配置模型；创建后可通过已有模型选择器调整。这项功能涉及模型目录和创建会话接口，未在本次局部界面修正中增加。
